# Instructions Claude Code

Lis et respecte intégralement `AGENTS.md` avant toute action sur ce projet.

En particulier : n'utilise jamais directement `netlify deploy --prod`.
Utilise uniquement `npm run deploy:preview` pour un aperçu et
`npm run deploy:production` pour la production. Ces règles restent valables dans
tous les nouveaux chats et tous les worktrees.
